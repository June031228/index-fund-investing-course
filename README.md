# 指数基金·稳健成长课

> 面向金融理财小白、偏稳健型的长期投资课程。
> 核心方法：**宽基指数基金 + 股债搭配 + 定投 + 再平衡**
> 学习周期：8 周 56 天，**每日发布一小节**。

## 适合人群

- 金融理财零基础，想系统学习投资的小白
- 偏稳健型，追求长期稳健增值而非短期暴富
- 有持续收入（上班族/双职工家庭），想用纪律化方式投资
- 目标：建立自己的指数基金投资体系

## 核心方法论

```
宽基指数基金（赚市场平均收益）
    + 股债搭配（控制波动）
    + 定投（平滑成本、对抗情绪）
    + 再平衡（纪律性低买高卖）
    = 长期稳健增值
```

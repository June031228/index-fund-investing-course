# Day 28：第四周总结与定投计划制定

> 第4周 · 定投与估值 ｜ 学习难度：基础
> 学习周期第 28 天 ｜ 预计阅读 9 分钟

---

## 学习目标

学完本节，你能把第4周的全部知识整合成一份**完整、可执行、经得起检验的个人定投计划表**——包含定投三要素、估值触发规则和止盈纪律——并用12个月的历史数据完成一次纸上演练，确认自己的计划能跑通。

## 名词解释

- **定投计划三要素**：定投金额、定投周期、止盈目标。三者加上"产品"和"估值规则"，构成一份完整定投计划。
- **估值增强**：在标准定投基础上叠加"低估多投/高估少投"的调节器（day-27），是普通定投的升级版。
- **定投计划表**：把产品、日期、金额、规则、止盈点全部写成一张表，打印/存手机，是执行与复查的依据。
- **纸上演练**：用历史数据模拟运行自己的计划，检验参数合理性、提前熟悉执行流程，全程不花真钱。
- **红利再投资**：分红自动转成份额继续投资，让复利滚动。定投基金建议统一选择此项。
- **复核周期**：定期检查计划执行情况的时间间隔（建议每季度/每年）。用于核对估值分位、基金健康度、金额是否需要调整。
- **执行偏差**：实际行为与计划不符的偏差（如某月因"害怕"而暂停）。复盘时如实记录，是改进纪律的关键。

## 知识点

1. **第四周知识地图（复习）**
   - **day-22**：定投=定期定额，用纪律对抗人性，匹配上班族现金流；
   - **day-23**：微笑曲线——下跌段积累低价份额，反弹时盈利，坚持不中断是关键；
   - **day-24**：定投三要素——金额（可支配收入10-20%，宁少勿断）、周期（月投+发薪日次日）、止盈（20-50%稳健选30%）；止盈不止损；
   - **day-25**：PE=回本年限，1/PE=盈利收益率，与国债收益率对比判断贵贱；宽基看PE，周期股看PB；
   - **day-26**：估值分位——当前PE在历史中的位置，<30%低估、>70%高估；
   - **day-27**：触发规则——低估1.5-2倍多投、正常标准、高估减半/暂停/止盈，不猜底、分批执行。

2. **完整定投计划=三要素+估值增强+纪律**
   一份合格的定投计划，缺一不可：
   ```
   ① 产品：day-21选定的宽基指数基金（如沪深300联接A）
   ② 三要素：金额=可支配收入×15%，周期=每月发薪日次日，止盈=30%
   ③ 估值增强：低估1.5倍/深度低估2倍/高估减半/深度高估止盈
   ④ 纪律：跌不停投、到点就买、止盈分批、不用应急金
   ⑤ 复查：每季度核对分位，每年复查基金健康度与金额
   ```
   计划的价值不在"预测准"，而在**"提前写死、按表执行"**——行情越剧烈，计划越值钱。

3. **纸上演练为什么重要**
   - 真实定投前，用历史数据跑一遍自己的参数（金额/倍数/止盈），能暴露三个问题：
     ① 加码资金是否够用（低估期可能持续很久）；
     ② 止盈点是否符合自己的心理承受力（到30%真的舍得卖吗）；
     ③ 流程是否熟练（查分位→对表→操作）。
   - 演练不花一分钱，却能避免真实资金交学费。**先演练、再实投**是专业投资者的标准做法。

4. **制定计划的常见错误（提前避坑）**
   - 金额过大导致中途断投（违"宁少勿断"）；
   - 止盈点设太高（50%+）却承受不了回撤，最终"纸面富贵"；
   - 把"高估暂停定投"误执行成"清仓离场"——停买≠卖光，止盈才卖；
   - 加码资金临时挪用生活费——弹药库必须提前预留；
   - 频繁修改规则——规则一改再改等于没有规则。

## 操作指导

**第一步：填好个人定投计划表**
   复制下面表格，逐行填写（关键数字已用＿＿＿标出）：
   | 项目 | 内容 |
   |---|---|
   | 投资目标 | ＿＿＿（例：10年家庭储备金） |
   | 定投产品 | ＿＿＿（名称+代码，来自day-21清单） |
   | 定投日 | 每月＿＿日（发薪日次日） |
   | 标准金额 | ＿＿＿元/月（可支配收入10-20%） |
   | 低估加码 | 分位<30%时投＿＿＿元（1.5-2倍） |
   | 高估动作 | 分位>70%时投＿＿＿元或暂停；>80%启动止盈 |
   | 止盈目标 | 收益率＿＿＿%时分批卖出（建议30%） |
   | 止盈后资金 | ＿＿＿（再投入新一轮/暂存债基） |
   | 分红方式 | 红利再投资 |
   | 复查计划 | 每季度查分位；每年复查基金健康度 |
   | 弹药库 | 来源＿＿＿、目标＿＿＿元 |

**第二步：做12个月纸上演练**
- 选一段历史行情（可直接复用day-23的模拟表，或另选）；
- 按你的计划表参数（金额、倍数）逐月模拟，加入低估/高估月份的加减码；
- 算出：总投入、期末市值、收益率、回本点；
- 对照止盈点检验：中途是否触发了止盈？执行得是否干脆？

**第三步：对照计划自检**
- 自检清单：①产品选对了吗？②金额能坚持吗？③止盈点合理吗？④低估加码资金够吗？⑤止盈后资金安排了吗？
- 全部打钩→计划可以进入"待执行"状态（第7周实操课会教你真正下单）；有未打钩项→回到对应课程补齐。

**注意事项**：① 计划表写好≠万事大吉，每季度要回到这张表核对执行；② 真实执行时所有操作在App里"到点做、做完记录"，不要临时发挥；③ 本课是第4周终点，但只是整个体系的中间站——第5周开始学"股债搭配"，你的单一定投计划将升级为组合配置。

## 案例

**一份完整的定投计划样例**

背景：小白阿伟（day-21案例），月收入8000元，月开支4000元，可支配收入4000元，无证券账户，偏稳健。

**他的定投计划表（完整版）：**
| 项目 | 内容 |
|---|---|
| 投资目标 | 10年后储备100万元家庭资金（起步阶段） |
| 定投产品 | 某某沪深300ETF联接A（规模158亿、费率0.2%、跟踪误差0.28%） |
| 定投日 | 每月6日（5日发薪） |
| 标准金额 | 600元/月（可支配收入4000×15%） |
| 低估加码 | 分位<30%→900元/月；<20%→1200元/月+一次性加仓5000元（弹药库） |
| 高估动作 | 分位70-80%→300元/月；>80%暂停+启动止盈 |
| 止盈目标 | 收益率30%时分批卖出（先1/3，每再涨5%卖1/3） |
| 止盈后资金 | 分成24个月重新定投+10%奖励自己 |
| 分红方式 | 红利再投资 |
| 复查计划 | 每季度看分位；每年3月复查基金规模/费率 |
| 弹药库 | 每月额外留200元入货基，目标1.2万元，仅低估区使用 |

**他的12个月纸上演练（摘录，数据为教学模拟）：**
- 第1-6个月，估值分位35%-45%（正常）→ 每月600元；
- 第7-9个月，跌至分位25%-28%（低估）→ 每月900元；
- 第10个月，跌至分位18%（深度低估）→ 每月1200元+动用弹药库3000元；
- 第11-12个月，回升至正常区 → 每月600元。
- 全年投入合计：600×6+900×3+1200+600×2+3000 = 3600+2700+1200+1200+3000 = **11700元**；
- 期末市值约12500元，**收益率约6.8%**（行情整体震荡但低估区筹码发力）；
- 对比"无脑每月600元"的普通定投（投入7200元、收益率约2%）：**估值定投投入更多、赚得也更多，资金效率明显更高**。

阿伟的结论："我的计划已经通过纸上演练，参数合理、资金够用，可以等到第7周实操课去真正开始执行了。"

> **核心结论**：一份好计划 = 明确的产品 + 可坚持的金额 + 触发清晰的估值规则 + 写死的止盈纪律。纸上演练通过后，剩下的就是"到点执行、每季复查"。案例数据为教学模拟，仅用于方法演示，不代表实际收益。

## 练习

1. 完成你的个人定投计划表（全部11项逐行填写，缺一不可）。
2. 用历史数据做一轮12个月的纸上演练，输出总投入、期末市值、收益率三个数字，并说明你的参数是否经得起检验。
3. 思考题：如果模拟中发现"低估区加码后弹药库只剩20%"，你的计划需要怎样调整？（提示：降低一次性加仓比例或提高弹药库目标）
